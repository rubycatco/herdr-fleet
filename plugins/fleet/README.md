# fleet

Run fleets of coding-agent lanes in Herdr panes from Claude Code. Open a lane with `/fleet:lane`, run critic rounds with `/fleet:review`, keep context small with `/fleet:context`, and move a session or lane to a new pane with `/fleet:handoff`. remuda is optional: with it, lanes can run on different accounts (`/fleet:accounts`); without it, every lane uses the agent's own login. Run `/fleet:onboard` once to write your conventions file.

Full documentation: the README at the root of the herdr-fleet repository.
